# CITY LIFE 3D V6.1 — OUTBREAK FIX

نسخة تطويرية لنموذج لعبة عالم مفتوح ثلاثية الأبعاد للأندرويد، مبنية بلغة C99 ومكتبة raylib 5.5.

## ما أُضيف في V6

### عالم المدينة
- شبكة مدينة إجرائية بمقاس **50×50 كتلة**.
- نحو **9,772 مبنى إجرائياً** موزعاً على أحياء المدينة، مع ساحة مركزية.
- نحو **1,170 شجرة** موزعة على الأحياء والحدائق.
- 128 شخصية مدنية و72 مركبة مرور و12 نموذج سيارة إجرائي.
- مناطق للمطار والميناء والساحل والصحراء وميدان التفحيط.

### البقاء والمواجهات
- موجات أعداء تتضمن زومبي وعناصر عصابات خيالية؛ ويمكن للفئتين الاشتباك عند اقترابهما.
- خمسة فصول/مستويات من الموجات، مع زيادة صعوبة الأعداء والمكافآت.
- هجوم قريب باليد وزر مستقل للضرب، وتصويب/إطلاق بالأسلحة.
- صحة وجوع ودرع وذخيرة ونقاط ومكافآت نقدية.
- ثلاثة أسلحة خيالية: سلاح بداية، بندقية، وشوتغن.
- متجر أسلحة لشراء الأسلحة والذخيرة.
- مكافآت نقدية ونقاط عند هزيمة الأعداء واجتياز الموجات.

### المتاجر والمنزل
- متجر أسلحة قابل للدخول والشراء.
- سوبرماركت للطعام والعلاج والذخيرة.
- مطعم لشراء وجبة واستعادة الجوع والصحة.
- منزل داخلي بسيط مع سرير للنوم.
- النوم ينقل ساعة اللعبة إلى السابعة صباحاً ويعيد بعض موارد اللاعب.

### واجهة اللعب
- واجهة عربية مبنية على أطلس نصوص.
- عداد الأموال والنقاط والمستوى والصحة والجوع والدرع.
- ساعة ويوم داخل اللعبة، مع تعاقب الليل والنهار.
- أزرار منفصلة حسب الحالة: مشي/قتال خارج السيارة، وقيادة داخل السيارة.
- زر راديو مخصص مع خمس الأغاني التي رفعها المستخدم فقط.

## الموسيقى

المجلد `assets/music` يحتوي على خمس ملفات OGG الخاصة بالمستخدم فقط، ويحدد `playlist.txt` أسماءها وعناوينها. حُذفت المقاطع النموذجية الستة من الإصدارات السابقة.

## البناء

يستخدم GitHub Actions الملف:

`.github/workflows/android-apk.yml`

افتح المستودع في GitHub ثم Actions ثم شغّل `Build CITY LIFE 3D V6.1 Outbreak Fix APK`. عند نجاح البناء، نزّل ملف APK من قسم Artifacts.

## حدود يجب معرفتها

- المباني والسيارات والشخصيات الحالية مرسومة إجرائياً بأشكال ثلاثية الأبعاد داخل raylib. هذه ليست حزمة موديلات فوتوغرافية واقعية أو PBR، ولا تطابق جودة لقطة GTA المرجعية.
- المتاجر والغرف مبسطة هندسياً لكنها مرتبطة بتفاعلات شراء ونوم فعلية في الكود.
- نظام العصابات والزومبي هو قتال خيالي محلي بالموجات؛ توجد اشتباكات بسيطة بين الفئتين عند التقارب، وليس محاكاة موسعة لسيطرة العصابات على الأحياء أو لعباً شبكياً.
- لا يوجد بعد حفظ دائم شامل للمال والمخزون والتقدم بعد إغلاق التطبيق.
- تم إجراء فحص صياغة C99 محلياً وفحوص أصول وملفات البناء. لم يُنفذ بناء Android NDK نهائي أو اختبار APK على جهاز في بيئة التحرير هذه؛ GitHub Actions هو اختبار البناء الفعلي.

هذه نسخة V6 تطويرية قابلة للبناء، وليست إصداراً تجارياً مكتملاً أو لعبة بمستوى إنتاج AAA.
